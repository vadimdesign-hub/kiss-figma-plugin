# Kiss — Figma Plugin

Набор утилит для помощи в работе: выравнивание секций, управление приоритетами, поиск похожих объектов и другие инструменты работы в Figma. Плагин поддерживает компактную плавающую панель, через которую можно запускать любую команду в один клик — без необходимости каждый раз открывать меню Plugins.

## Функционал

### ⚡ Выровнять все секции
Автоматически выравнивает все секции на странице по сетке — расставляет их в ряды с одинаковыми отступами. Ничего не нужно выделять, плагин берёт все секции сам.

Если перед запуском выделить **несколько (2 и более) секций** — команда выровняет только их между собой, по тому же принципу, не трогая остальные секции на странице. Точкой отсчёта в этом случае служит исходный верхний левый угол самой верхней левой из выделенных секций (а не левый край страницы, как при выравнивании всех секций).

На кнопке есть чекбокс **«Максимально плотная компоновка»** — он появляется на кнопке только когда в Figma реально выделено 2 и более секций (в остальное время скрыт). Вместо рядов раскладывает секции по колонкам (masonry-сетка), стремясь получить компактный, близкий к квадрату результат без пустот между секциями. Для этого:

- сначала у каждой секции обрезается пустой запас вокруг содержимого (ширина и/или высота — где реально есть запас);
- затем допускается немного растянуть ширину некоторых секций под ширину колонки (обычно в пределах ~200 px, в крайнем случае — больше, если иначе не скомпоновать).

Любое изменение размера — и обрезка, и растяжение — происходит симметрично из центра: содержимое секции остаётся на месте, лишнее/недостающее пространство добавляется или убирается поровну со всех сторон.

### ➡️ Расширить вправо / Дублировать вправо
Работает по-разному в зависимости от того, что выделено.

Если выделена **секция** — увеличивает её ширину на 620 px вправо, все секции правее сдвигаются.

Если выделен **фрейм внутри секции** — дублирует его вправо: секция расширяется на ширину фрейма + 80 px, клон ставится сразу после оригинала, правые секции сдвигаются.

### ⬅️ Расширить влево / Дублировать влево
Если выделена **секция** — увеличивает её ширину на 620 px влево (контент внутри сдвигается вправо), правые секции сдвигаются.

Если выделен **фрейм внутри секции** — дублирует его влево: клон встаёт на место оригинала, оригинал и все фреймы правее сдвигаются вправо, правые секции тоже сдвигаются.

### 📐 Выровнять + тёмная
Выравнивает фреймы внутри секции с одинаковыми отступами. Если фреймы высокие (больше 960 px) — автоматически дублирует их во второй ряд снизу и переключает дубли в тёмную тему через переменные Figma (Appearance → Dark).

На кнопке в панели инструментов есть чекбокс с иконкой клавиатуры — если его включить, перед выравниванием под каждым экраном автоматически добавится компонент клавиатуры.

### 🗂️ Обернуть + выровнять
Выдели любые объекты — плагин обернёт их в новую секцию и выровняет в один ряд. Если выделена уже существующая секция — просто выровняет содержимое внутри неё. Работает с любыми типами объектов: фреймы, компоненты, группы и т.д.

### 🔄 Замена instance
Выдели несколько объектов, последним — эталонный экземпляр. Плагин заменит все остальные выделенные объекты на копии эталона, сохранив их позиции.

По умолчанию каждая копия растягивается под размер заменяемого объекта. Чекбокс на кнопке отключает это — размер копии остаётся как у эталона.

### 🏷️ Переименовать
Копирует имена из первой половины выделения во вторую. Выдели сначала объекты-источники (с нужными именами), затем, не снимая выделения, добавь столько же объектов-целей — итоговое количество всегда чётное. По нажатию кнопки первая цель получает имя первого источника, вторая — второго, и т.д.

Порядок определяется тем, в каком порядке объекты реально добавлялись в выделение, пока открыта панель инструментов, а не их положением на холсте.

### 📦 Перенести объекты
Копирует объекты из первой половины выделения внутрь контейнеров из второй половины (оригиналы остаются на месте). Выдели сначала объекты, которые нужно скопировать (например по одному внутреннему объекту с каждого из нескольких экранов), затем, не снимая выделения, добавь столько же целевых фреймов. Копия первого выделенного объекта попадёт в первый целевой фрейм, копия второго — во второй, и т.д.

Абсолютная позиция на холсте сохраняется: если целевой фрейм расположен так же, как исходный (например экраны выстроены в ряд), копия окажется в том же месте внутри нового фрейма. Порядок, как и в «Переименовать», определяется реальным порядком добавления в выделение.

### ✂️ Нарезка
Универсальный инструмент подготовки ассетов. Работает в трёх режимах в зависимости от чекбоксов на кнопке:

- **Без чекбоксов (по умолчанию)** — нарезка 1px. Каждый выделенный объект оборачивается во фрейм с отступом 1px, все результаты складываются в секцию «Нарезка».
- **Чекбокс «2.67»** — масштабирование. Каждый выделенный объект увеличивается в 2.67 раз, размеры округляются до чётных чисел. Результаты помещаются в секцию «Нарезка / Сервер».
- **Чекбокс «Продукт»** — серверные иконки. Каждый объект оборачивается во фрейм с отступом 1px, создаются три масштабированные копии — 80×80, 120×120 и 240×240. Результаты складываются в секцию «Нарезка / Продукт».

Чекбоксы взаимоисключающие — можно выбрать только один. После выполнения команды чекбокс автоматически сбрасывается.

### 🖼️ Размеры в арт
Автоматически проставляет размеры артов. Первый текстовый слой показывает реальный размер (W×H px), второй — итоговый размер арта в нужном масштабе.

### 🔍 Похожие
Выдели любой объект и запусти команду — плагин найдёт по всей странице все объекты с точно таким же именем и размерами, выделит их разом и подстроит вьюпорт, чтобы все было видно. Чекбокс на кнопке — включён: ищет только внутри текущей секции.

### 🔍 Похожие (экспериментальная, с настройками)
Соседняя кнопка с тонкой синей обводкой — так она всегда отличается от обычной «Похожие», обводка отмечает, что это отдельная экспериментальная функция. Массовая замена по образцу. Пока открыта её панель — кнопка дополнительно заливается синим, чтобы было видно, что функция сейчас активна. Панель открывается по клику **в любом случае**, независимо от выделения. Удобнее всего заранее выделить два объекта — сначала образец для поиска (имя + размер), вторым — на что заменять, тогда поиск запустится сразу. Но можно открыть и пустую панель, а образец и замену выбрать по отдельности внутри неё.

**Слева** — «Объекты, которые меняем»: прокручиваемый список найденных похожих объектов, количество — небольшим значком рядом с заголовком (или подсказка, если ничего не выбрано). Кнопка **«Выбрать другой»** в шапке — выдели в Figma новый образец и нажми «Сохранить» (или «Отмена») — плагин заново найдёт похожие на него и обновит список. Сам целевой объект в этот список не попадает, даже если совпадает по имени и размеру.

**Справа** — «Целевой объект»: имя замены крупно по центру (или подсказка, если не выбран). Такая же кнопка **«Выбрать другой»** — работает так же, но меняет саму замену, список источников не трогает.

Клик по пункту списка или по имени замены переводит фокус Figma на него.

Снизу — панель кнопок: слева **«Очистить всё»** (снимает выделение в Figma) и **«Далее»** (переводит фокус на следующий пункт без замены); справа — кнопки замены:
- **Заменить** — заменяет текущий выбранный в списке объект на замену (сохраняется размер замены, а не исходного объекта).
- **Заменить + далее** — то же самое, и сразу переходит к следующему незаменённому пункту.
- **Заменить всё** — заменяет разом все незаменённые пункты списка.

Специальной кнопки закрытия у панели нет — повторный клик по синей кнопке, пока панель открыта, закрывает её и снимает выделение в Figma.

Уже заменённые пункты помечаются галочкой. Чекбокс на кнопке — как у обычной «Похожие»: включён — ищет только в текущей секции.

### 🟠 Средний приоритет / 🔴 Высокий приоритет / 🟢 Задача выполнена / 🔵 На ревью
Четыре тега статусов, которые добавляются к выделенному объекту. Если тег уже есть — обновляет цвет и текст. Образуют простую систему статусов прямо внутри Figma. На панели инструментов отображаются компактной сеткой 2×2.

### 🚀 Ready for Dev
Помечает секции официальным статусом Figma «Ready for Dev» — разработчики видят его в режиме Dev Mode.

- Если выделены секции — переключает статус только у них.
- Если ничего не выделено — переключает все секции на странице: все помечены → снимает; хотя бы одна не помечена → ставит всем.

### ⬆️⬇️ На передний / задний план
Составная кнопка из двух половинок — стрелка вверх сверху, стрелка вниз снизу.

- **Стрелка вверх** — перемещает каждый выделенный объект на самый верх иерархии внутри его родителя (как «На передний план» в Figma — объект оказывается поверх всех остальных слоёв того же родителя).
- **Стрелка вниз** — перемещает объект на самый низ иерархии внутри родителя (как «На задний план» — оказывается под всеми остальными слоями того же родителя).

Работает с любым количеством выделенных объектов сразу — каждый передвигается внутри своего собственного родителя, не выходя за его пределы.

### ✨ QA
Выдели фрейм или компонент и нажми «QA» — открывается панель с настройками (сам анализ ещё не запускается). Три тумблера:

- **Скрытые элементы** — учитывать в анализе скрытые слои (по умолчанию выключено).
- **Оставлять комментарии** — включить, чтобы находки сразу проставлялись комментариями прямо в Figma; выключено — только анализ, файл не меняется (по умолчанию выключено).
- **Игнорировать itemSpacing** — не проверять отступы между элементами (по умолчанию включено).

По кнопке **«Начать анализ»** отправляет выделенный объект локальному AI-агенту (Python-скрипт на твоём компьютере, `localhost:5000`) и открывает живой лог — находки появляются по одной, по мере того как агент их находит. Клик по находке в списке переводит фокус Figma на связанный с ней объект. Повторный клик по кнопке «QA», пока панель открыта, закрывает её.

Ссылку на файл плагин обычно определяет сам. Если не получилось (например в Desktop-приложении) — панель попросит вставить её вручную: ⌘L «Скопировать ссылку на выделение» → вставить в поле.

Требует запущенного локального агента (см. `agent/PLUGIN_INTEGRATION.md`) — если он недоступен, панель покажет предупреждение.

### 🗄️ В архив
Выдели что угодно — секции, фреймы, отдельные объекты, в любом количестве — и нажми «В архив». Плагин находит в файле страницу с именем **Archive** или **Архив** (без учёта регистра, опечатка «Arhive» тоже подойдёт) и переносит туда выделенное.

Если выделены и родитель, и что-то внутри него (например секция и фрейм в ней) — переносится только родитель целиком. Всё вставляется одним блоком, сохраняя расположение объектов друг относительно друга, но целиком ниже всего, что уже есть на странице архива — чтобы точно ни с чем не пересечься.

После переноса на кнопке появляется маленькая круглая серая кнопка со стрелкой вправо — клик по ней переключает на страницу архива и сразу выделяет и приближает только что перенесённое. После перехода стрелка разворачивается влево (это и означает «назад», подписи нет) — клик возвращает на ту же страницу и в то же место во вьюпорте, откуда переходили (само выделение не восстанавливается — просто «то же место»). После возврата кнопка исчезает, до следующего переноса в архив.

### ✨ Agent
Выдели слой и нажми «Agent» (кнопка с переливающимся фиолетовым AI-градиентом) — плагин открывает в браузере по умолчанию локальный инструмент поиска по макетам, сразу с названием выделенного объекта в строке поиска: `http://127.0.0.1:8000/?q=<название>&prop_<Свойство>=<значение>`. Если выделено несколько слоёв — ищет по первому (появится уведомление); если ничего не выделено — подскажет выделить слой.

- **Название**: у инстанса компонента — название компонента (у варианта из набора — название набора), а не слоя, потому что слой могли переименовать. У фреймов, текстов и прочего — название слоя.
- **Фильтры**: вариантные свойства инстанса (Size, Color…) передаются параметрами `prop_<Свойство>` (пробелы в имени → `_`, значения через `encodeURIComponent`), и Search Agent сам отмечает по ним галочки в блоках фильтров. Значения, которых нет среди найденного, он молча пропускает. Булевы и текстовые свойства не передаются — в базе их нет.
- Пример: `http://127.0.0.1:8000/?q=Primary%20Button&prop_Size=B%2048px&prop_Color=Ghost`.
- **Шейп или вектор** (прямоугольник, эллипс, вектор, линия, звезда, boolean и т.п.): передаётся только цвет — `http://127.0.0.1:8000/?color=EF9A3E`, без названия. Берётся верхняя видимая сплошная заливка; если заливок нет совсем (контурная иконка, линия) — верхняя видимая обводка. Если сверху градиент или картинка (сплошного цвета нет) — поиск идёт по названию слоя, с уведомлением.

Плагин сам в сеть не ходит, а просто открывает ссылку (`figma.openExternal`), поэтому правки `networkAccess` в `manifest.json` не нужны. Если сервер инструмента не запущен, он стартует сам при открытии ссылки (служба автозапуска на порту 8000).

### 🎛️ Панель инструментов
Открывает компактную плавающую панель со всеми командами плагина в виде кнопок. Запускаешь один раз — панель висит поверх канваса. По умолчанию свёрнута: стрелки ⬅️➡️ (видны всегда), несколько первых команд (по умолчанию 3, настраивается) и узкая кнопка **⋮** справа, которая раскрывает все команды.

Кнопки можно перетаскивать для изменения порядка — порядок сохраняется между сессиями.

В раскрытом виде (после наведения или клика по «⋮») справа появляется узкая колонка: сверху пин, снизу шестерёнка **⚙️ Настройки** (без подписи) с блоками:

- **Скрытые пункты** — перетащи сюда кнопку из основного ряда, чтобы скрыть её; перетащи обратно наверх — она вернётся.
- **Кастомизация главного вида** — два счётчика с плюс/минус:
  - **Кнопок в свёрнутом виде** — сколько обычных кнопок показывать при свёрнутой панели (по умолчанию 3). Стрелки ⬅️➡️ и сама кнопка «›» в счёт не идут, они видны всегда.
  - **Изменение ширины кнопок** — плюс увеличивает ширину каждой обычной кнопки на 1 px, минус уменьшает (можно уйти в минус). Стрелки ⬅️➡️ и «›» размер не меняют.
  - **Изменение высоты кнопок** — то же самое, но по высоте, шаг тоже 1 px.
  - **Тема оформления** — переключатель **Светлая / Тёмная** для самого плагина. Применяется сразу (без «Сохранить» и перезапуска) и запоминается между сессиями; это та же тема, что выбирается в окне ⚙️ Настройки.
- **Составные кнопки (↑/↓)** — отдельный счётчик **«Изменение ширины»** только для составных кнопок-«столбиков» (например «На передний/задний план»). Высота у них всегда равна высоте обычной кнопки и отдельно не настраивается — половинки просто делят её пополам.

Повторное нажатие «Настройки» сворачивает панель; при сворачивании стрелкой «‹» она закрывается автоматически. Все эти настройки сохраняются между сессиями, как и порядок кнопок.

### ⚙️ Настройки
Открывает окно настроек плагина:

- **Стиль иконок** — переключает иконки панели инструментов и FAQ между SVG (монохромные линейные) и Emoji (цветные).
- **Тема** — переключает оформление между светлой и тёмной темой. Тема применяется к панели инструментов, настройкам и FAQ.

Все настройки сохраняются и применяются автоматически.

### 📖 FAQ
Открывает встроенную справку по всем командам плагина прямо внутри Figma. Каждая команда сопровождается превью кнопки как она выглядит на панели. Тема и стиль иконок FAQ соответствуют выбранным в настройках.

## Особенности

- Не требует API-ключей и внешних сервисов — всё работает локально внутри Figma
- Работает с любыми типами объектов: фреймы, компоненты, главные компоненты, группы
- Поиск по всей странице, включая содержимое секций
- Переключение тёмной темы через переменные Figma (Variable Modes / Appearance)
- Компактная плавающая панель инструментов с перетаскиванием кнопок
- Два стиля иконок (SVG / Emoji) и две темы (светлая / тёмная)
- Встроенный FAQ с превью кнопок и описанием каждой команды

## Как установить

1. Скачай или склонируй репозиторий
2. Открой Figma → Plugins → Development → Import plugin from manifest
3. Выбери `manifest.json` из папки проекта
4. Плагин появится в списке плагинов разработки
